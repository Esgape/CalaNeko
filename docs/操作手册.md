## 三、使用教程

### 启动方式
1. **源码运行**：`pip install -r requirements.txt` → `python src/game_boost_web.py`
2. **bat 启动**：双击「启动 CalaNeko.bat」（自动检测 Python/psutil，非管理员时提示）
3. **exe 独立版**（未随公开仓库分发，本地 dist_release 有）：双击即用，自动请求管理员权限

### 界面操作
- 打开浏览器访问 `http://127.0.0.1:18765`
- **开始监控**：点击后开始按预设优化进程
- **预设切换**：下拉选择预设（通用/卡拉彼丘FPS/单机/联网二游）
- **存为预设**：自定义配置后保存
- **退出**：退出按钮会先还原所有进程优先级再退出
- **日志导出**：生成含系统信息的 txt

### 常用启动参数（v0.3.0+）
| 参数 | 作用 |
|---|---|
| `--minimized` | 启动后不自动打开浏览器 |
| `--autostart` | 注册 HKCU 开机自启后退出 |
| `--check-update` | 检查更新后退出 |

## 四、技术要点

- **Win32 API**：通过 ctypes 调用（NtSetInformationProcess 0x27 内存优先级等）
- **崩溃恢复**：修改前写磁盘 `tweak_ledger.json`（原子写入：临时文件+os.replace），启动时自动恢复
- **单实例**：端口探测（connect_ex 127.0.0.1:18765）+ Mutex 双重保障
- **端口**：18765（固定常量 PORT，HTTP 服务共用）
- **权限**：管理员完整功能；普通权限仅优化当前用户会话进程

## 五、常见问题

**Q：双击没反应？**
A：检查是否已有实例在运行（单实例互斥），浏览器应自动打开 `http://127.0.0.1:18765`。

**Q：提示非管理员权限？**
A：右键 bat「以管理员身份运行」，或使用 exe 版（自动提权）。普通权限功能受限。

**Q：游戏还是卡？**
A：检查预设是否匹配游戏类型；FPS 可关闭 ACE 降权（部分反作弊会互相冲突）。

**Q：如何反馈问题？**
A：Web 界面「日志导出」生成日志文件，连同系统信息一起反馈。
